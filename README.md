# .github — treew-inc

Este repositorio contiene los archivos de salud comunitaria y configuración por defecto para toda la organización **treew-inc** en GitHub.

## Administración

Este repositorio es administrado por el **Grupo de Calidad y Soporte Técnico**.  
Para proponer cambios, abre un Pull Request con la justificación correspondiente.

Cualquier modificación a los archivos de este repositorio afecta a toda la organización — los cambios deben ser revisados y aprobados antes de mergearse.
