# .github — treew-inc

Este repositorio contiene los archivos de salud comunitaria y configuración por defecto para toda la organización **treew-inc** en GitHub.

## ¿Qué contiene este repositorio?

Los archivos aquí presentes aplican automáticamente como valores por defecto a todos los repositorios de la organización que no tengan su propia versión:

| Archivo | Propósito |
|---|---|
| `SECURITY.md` | Política para reportar vulnerabilidades de seguridad |
| `CONTRIBUTING.md` | Guía de contribución y convenciones de desarrollo |
| `CODE_OF_CONDUCT.md` | Código de conducta para colaboradores |
| `LICENSE` | Licencia de uso del software |
| `PULL_REQUEST_TEMPLATE.md` | Plantilla estándar para Pull Requests |

## Administración

Este repositorio es administrado por el **Grupo de Calidad y Soporte Técnico**.  
Para proponer cambios, abre un Pull Request con la justificación correspondiente.

Cualquier modificación a los archivos de este repositorio afecta a toda la organización — los cambios deben ser revisados y aprobados antes de mergearse.
